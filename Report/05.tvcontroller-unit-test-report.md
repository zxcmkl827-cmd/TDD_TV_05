## 2. 테스트 전략

### 2.1 테스트 픽스처

```cpp
class ControllerTest : public ::testing::Test {
protected:
  std::unique_ptr<DevTuner> ptrDevTuner;
  std::unique_ptr<TVController> ptrTVController;

  void SetUp() override {
    ptrDevTuner = std::make_unique<DevTuner>(std::vector<int>{1, 4, 12, 56});
    ptrTVController = std::make_unique<TVController>(*ptrDevTuner);
  }
  // TuneTo(int), HasFavorite(int), AddFavorites(...) 헬퍼 제공
};
```

- **Fake:** `DevTuner` — 실제 채널 상태(`getCurrentCH`)로 동작 검증
- **초기 채널:** `0` (DevTuner 기본값)
- **선호 채널 프리셋:** `{1, 4, 12, 56}` — `PressNextFavorite` wrap·상향 이동 시나리오용

### 2.2 명명·주석 규칙

| 규칙 | 예시 |
|---|---|
| 테스트 클래스 | `ControllerTest` |
| 테스트 메서드 | `{API}_{행동요약}` — `PressNumber_TwoDigitsAutoApply` |
| 주석 (Given-When-Then 대체) | `// should_set_channel_12_when_two_digits_entered_without_confirm` |
| 검증 매크로 | 상태 확정 전 `ASSERT_EQ`, 최종 기대 `EXPECT_EQ` |

### 2.3 검증 포인트

| 계층 | 검증 대상 |
|---|---|
| 채널 변경 | `ptrDevTuner->getCurrentCH()` → `"0"` ~ `"99"` 문자열 (`std::to_string` 정책) |
| 선호 채널 목록 | `GetFavoriteChannels()` 크기·정렬·포함 여부 |
| no-op | 버퍼 비었을 때 `PressConfirm` / 빈 선호 목록 `PressNextFavorite` 시 채널 유지 |

## 5. 테스트 중 발견·수정한 결함

### 5.1 `PressNextFavorite` — `end()` 역참조 (UB)

**증상:** `PressNextFavorite_WrapsToSmallest`, `PressNextFavorite_SingleFavoriteWrapsToSelf` 실행 시

```text
Assertion failed: can't dereference out of range vector iterator
SEH exception 0xc000001d / 0xc0000005
```

**원인 (수정 전):**

```cpp
int NextChannel =
    it != FavoriteChannels.end() ? *it : *FavoriteChannels.end();  // UB
```

`std::upper_bound`가 `end()`를 반환할 때(현재 채널이 최대 선호 채널이거나 단일 항목과 같을 때) **유효하지 않은 이터레이터 역참조**가 발생했습니다. `Report/03` P0 이슈와 동일합니다.

**수정 (현재 코드):**

```cpp
int NextChannel =
    it != FavoriteChannels.end() ? *it : *FavoriteChannels.begin();
```

**의도:** 현재보다 큰 선호 채널이 없으면 **가장 작은 선호 채널로 순환** (`docs/requirements_analysis.md` C-11).
