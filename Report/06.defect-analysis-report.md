## 6. 최소 변경 수정 내용

### 6.1 DEF-TV-001 — `PressNextFavorite` wrap

**수정 전:**

```cpp
int NextChannel =
    it != FavoriteChannels.end() ? *it : *FavoriteChannels.end();  // UB
```

**수정 후 (현재):**

```cpp
int NextChannel =
    it != FavoriteChannels.end() ? *it : *FavoriteChannels.begin();
```

**요구사항:** 현재 채널보다 큰 선호가 없으면 정렬된 목록의 **최소 채널**로 순환 (`requirements_analysis.md` C-11).

### 6.2 DEF-TV-002 — `PressNumber` 컴파일 오류

`ApplyChannel(SelectedChannel);` 다음 줄의 **`햣` 1줄 삭제** (로직 변경 없음).

### 6.3 제약 준수

- `Tuner.h`, `remoteKey.h` — **미수정**
- C++17 스타일 유지 (`std::upper_bound`, `std::sort`, `std::remove` 등 기존 API 유지)
