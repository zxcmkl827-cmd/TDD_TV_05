## 문서 구성 요약

1. **범위·현황** — `TVController` API별 구현 상태(컴파일 오류 문자, `PressNextFavorite` wrap 결함, 미구현 검색/업·다운 포함)

2. **TEST_F 범위·우선순위 (P0→P2)**
   - `ControllerTest` — DevTuner 기반 상태 검증 (22건 ID 매핑, 5건 구현·나머지 계획)
   - `TVControllerMockTest` — 호출 계약 검증 (8건)
   - `TunerTest` / `ApprovalTest` — 보조·계약

3. **경계값** — 채널 `0`/`99`/`100`, 숫자 버퍼, 선호 목록, 검색·업/다운(선행 정의)

4. **예외·특이** — `invalid_argument`, `stoi` 실패, no-op, `"7"` vs `"07"` 등

5. **커버리지 (90%+)** — line ≥90%, branch ≥85%; CMake `--coverage` 확장 권장, `lcov`/`genhtml` 절차, 갭→테스트 매핑표

6. **품질 게이트** — P0 Green, 커버리지 90%, TDD로 미구현 API 선행 테스트

`requirements_analysis.md` §4의 30개 시나리오와 README 요구사항을 추적 매트릭스로 연결해 두었습니다. 구현·테스트 추가 시 이 문서의 ID(C-01, M-05 등)로 진행 상황을 갱신하면 됩니다.
